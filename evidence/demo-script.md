# 五分钟课堂演示脚本（R2）

> 对应 AC-42。每步给「做什么 / 看到什么 / 讲什么」。
> 前置：`node cli.mjs dev` 已启动；R1 在 `4173` 可同时打开做对比。

| # | 做什么 | 看到什么 | 讲什么 |
|---:|---|---|---|
| 0 | 并排打开 `127.0.0.1:4173`（R1）与 `127.0.0.1:4174`（R2） | R1 手写果摊、文字卡、10 种；R2 白底大留白、照片卡、14 种 | 「同一需求，两轮迭代；差异一眼可见」 |
| 1 | R2 登录 `userA / demo1234` | 导航出现「我的订单」 | 「身份与会话：服务端 sessions + HttpOnly Cookie」 |
| 2 | 浏览商品，把红富士加 2、香蕉加 1 | 行算式、合计、售罄态 | 「金额全整数分；库存真实扣减」 |
| 3 | 结账 | 收据：订单号、UTC 时间、商品快照、行小计 | 「订单落库，不再存浏览器」 |
| 4 | 刷新页面 → 我的订单 | 订单仍在 | 「持久化：重启服务也还在」 |
| 5 | 用 `userB` 登录，粘贴 `userA` 的订单号查询 | 403「订单不属于当前用户」 | 「权限：水平越权被拒绝」 |
| 6 | 用 `admin` 登录 → 管理 → 改价/改库存/下架 | 公开列表即时变化；下架商品移出 | 「管理端闭环；下架可再上架」 |
| 7 | 终端 `node cli.mjs --json db check` | 完整性检查输出 | 「运维与管理员 CLI；`--json` 可被脚本消费」 |
| 8 | 终端 `node scripts/verify.mjs` | PASS 摘要 | 「流程证据可一键复现」 |

**如实说明（课堂上也要讲）**：访客查单已移除（breaking）；会话无过期、无完整 CSRF；`node:sqlite` 为实验特性；视觉验收的截图与人工判定在 qa 环记录。
